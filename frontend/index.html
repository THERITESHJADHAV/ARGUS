📖 How IOC Detection Works
🌐 Outbound Connection Monitoring
Every packet's destination IP is checked against the blocklist in real-time. A match triggers an immediate HIGH severity alert.

If a source IP connects to 20+ unique ports within 60 seconds, a port scan alert is raised with HIGH severity.
🤖 ML Network Analysis
Network flows are analyzed by a Random Forest model (98.25% accuracy) trained on CIC-IDS2017/2018 features. Attacks flagged with CRITICAL/HIGH severity.
